# Product-Store
 This Project aims to build a website that business owners can download and deploy to sell their products. Detailed instructions on how to set up the environment will be provided soon.

 This project uses:
 - React.js to create reusable UI components
 - Next.js for routing and API connections
 - TypeScript to provide functionality and connect the other parts of the stack
 - CSS for styling and organization
 - PostgreSQL as the Database
 - pgAdmin 4 to manually interact with DB
 - Node.js to power the server-side application
 
 Integrating:
 - Better Auth
 
 Possible additions:
 - Prisma

## Objectives

### E-Commerce Core
 - Display a list of products
 - Add/Remove Products from the list
 - Window containing the product's details
 - Functional Database Connection
 - Filter Products based on name or price
 - Edit Product's information

### Users/Authorization
 - Create Accounts
 - Allow actions based on permission level
 - Store Accounts in Database
